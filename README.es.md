Gestión hotelera: API Laravel en `projet-hotel-back` y frontend en `projet-hotel-front`. `start-dev.sh` arranca PHP en el puerto 8000 y el servidor Node a la vez. Base de datos, JWT y colas están en `README.md`, `QUEUE_SETUP.md` e `INSTALL_GD.md`. La guía de uso es `GUIDE_UTILISATION.md`.

```bash
./start-dev.sh
```
